# Уголки 8×8

Игра «Уголки» в браузере: доска 8×8, по 12 фишек у каждого игрока, компьютер пяти уровней сложности.

Правила: фишка ходит на соседнюю клетку по вертикали или горизонтали либо прыгает через соседнюю фишку любого цвета (прыжки можно делать цепочкой). Побеждает тот, кто первым займёт весь угол соперника. За 40 своих ходов все фишки должны покинуть свой дом, иначе поражение.

Вся игра — один файл `index.html`, без сборки и зависимостей.
